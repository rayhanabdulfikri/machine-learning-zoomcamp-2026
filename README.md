# Machine Learning Zoomcamp 2026

Hands-on learning path for **machine learning engineering**, covering machine learning fundamentals, classical ML, deep learning, deployment, and production-oriented infrastructure.

## Overview

Machine Learning Zoomcamp is a practical course focused on building machine learning systems from development through deployment.

The learning path broadly covers:

- Machine Learning Fundamentals
- Regression & Classification
- Model Evaluation
- Tree-Based & Ensemble Models
- Neural Networks & Deep Learning
- Model Deployment
- Serverless Inference
- Kubernetes
- End-to-End ML Projects

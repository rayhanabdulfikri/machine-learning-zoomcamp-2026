# Machine Learning Zoomcamp 2026

A hands-on learning path focused on **machine learning engineering**, from core machine learning concepts to model deployment and production-oriented infrastructure.

## Overview

Machine Learning Zoomcamp is a practical course focused on building machine learning systems throughout the development lifecycle — from learning the fundamentals and training models to deployment and production.

The learning path covers:

- Machine Learning Fundamentals
- Regression & Classification
- Model Evaluation
- Tree-Based & Ensemble Models
- Neural Networks & Deep Learning
- Model Deployment
- Serverless Inference
- Kubernetes
- End-to-End ML Projects
